# Active Experiment — 2026-11-09

## Question
Can this site distribute the Wealth Experiment side-hustle system without creating a duplicate catalog?

## Existing path
Use AI Side Hustle as a discovery/distribution door for the Wealth Experiment free starter and eventual validated Launch Kit.

## Evidence to record
Outbound visits to canonical Wealth Experiment resource; completions; workshop interest; later paid kit decisions.

## Operating rules
- Publishing is not distribution.
- A page view, form start, booking click, or generated checkout is not a paid customer.
- Track relevant visits, useful actions, qualified conversations, explicit paid decisions, refunds/costs, and delivery time separately.
- Use tagged links or another source identifier when distributing the experiment.
- Review the result on a defined cadence and choose **continue / change / pause / stop**.
- Do not respond to weak results by automatically building more features.

## Stop rule
No duplicate paid product unless this audience shows a distinct need that the Wealth Experiment product cannot serve.

## Portfolio role
This site participates in the portfolio experiment system. It should either produce evidence for this question, route qualified demand to an existing offer, distribute an existing asset, or remain in maintenance. New discretionary build work should state which of those outcomes it serves.
